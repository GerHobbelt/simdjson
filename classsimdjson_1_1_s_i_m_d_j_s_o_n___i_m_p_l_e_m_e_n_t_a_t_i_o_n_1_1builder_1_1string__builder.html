Detailed Description

A builder for JSON strings representing documents.

This is a low-level builder that is not meant to be used directly by end-users. Though it supports atomic types (Booleans, strings), it does not support composed types (arrays and objects).

Ultimately, this class can support kernel-specific optimizations. E.g., it may make use of SIMD instructions to escape strings faster.

◆ move_to()

error_code simdjson::SIMDJSON_IMPLEMENTATION::builder::string_builder::move_to ( std::string & out)
inlinenoexcept

Moves the written JSON buffer into out, replacing its content, without copying it.

When the content fills at most half of the buffer, it is copied instead, so that a small result does not keep the whole buffer allocated. The builder is left empty: it keeps its buffer when the content was copied, and gives up its memory when the buffer was moved. Returns an error, and leaves out and the builder unchanged, if memory allocation failed.

The result may not be valid UTF-8 if some of your content was not valid UTF-8. Use validate_unicode() to check the content.
